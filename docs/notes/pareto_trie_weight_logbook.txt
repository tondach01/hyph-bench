Protocol
--------
- Scope: Gaussian-process paper rows where the current GPoptval/VC-0.005 result is more accurate than the best hand-tuned baseline but has a larger trie.
- Affected rows from brain/overleaf/latex/main.tex: cssk/cshyphen, cs/cshyphen_cstenten, cs/cshyphen_ujc, cs/wiktionary, el/wiktionary, is/hyphenation-is, ms/wiktionary, pt/wiktionary, tr/wiktionary, uk/wiktionary.
- Command shape: uv run python -m scripts.optimize_validation --iterations 30 --batch-size 5 --objective f17_trie --good-weight 3 --max-bad-weight 30 --max-threshold 1 --ucb-kappa 2.5, changing only --trie-weight and --output-dir.
- Selection interpretation: for trie-weight tuning, use the optimizer's exported objective-selected best point (highest objective_score / optimizer.best_so_far()). Keep VC-0.005 values separate for comparison, because VC-0.005 can select a larger high-F point even after the objective-selected point has crossed the size/accuracy trade-off boundary.
- Stopping rule: double lambda while selected held-out accuracy is better than the best hand-tuned baseline and selected trie is still larger. If trie becomes smaller/equal and accuracy is still better, record a Pareto-improvement lambda. If trie becomes smaller/equal but accuracy is worse, record overshoot and move to the next language.
